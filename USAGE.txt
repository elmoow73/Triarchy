Triarchy 사용법 (v1.0.0-rc8)
======================

[업데이트]
  새 버전 zip 을 받으면 예전과 같은 곳에 압축을 풀고 "덮어쓰기" 를 고르세요.
  항상 Triarchy 폴더로 풀리므로 프로그램이 여러 개 생기지 않습니다.
  로그인과 설정은 다른 곳에 저장되어 있어서 덮어써도 그대로 남습니다.
  (덮어쓰기 전에 Triarchy 앱은 꺼 두세요)

[실행]
  Triarchy.exe 를 더블클릭하면 됩니다.
  처음 실행할 때 "Windows의 PC 보호" 파란 창이 뜨면
  "추가 정보" -> "실행" 을 누르세요. (서명 안 된 직접 만든 앱이라 뜨는 경고입니다)

[처음 한 번: 로그인]
  세 칸에서 각각 ChatGPT, Claude, Gemini 에 로그인하세요.
  로그인은 칸마다 따로 저장되고, 앱을 껐다 켜도 유지됩니다.
  (사이트가 "창을 닫으면 로그아웃" 방식으로 로그인시켜도 30일 동안 유지되게 해 두었습니다.
   로그인을 끝낸 다음 1분쯤 지나 앱을 끄면 가장 확실합니다.)

[같이 보내기]
  세 칸은 화면 위에서 아래까지 길게 쓰고, 공통 입력창은 그 위에 작은 창으로 떠 있습니다.
  - "⠿ 공통 입력" 글자를 마우스로 끌면 원하는 곳으로 옮길 수 있습니다.
  - "📌 아래에 고정" 을 누르면 창 아래쪽에 가로로 길게 붙습니다. "↗ 띄워서 쓰기" 로 다시 띄울 수 있습니다.
  - "▼ 접기" 를 누르면 숨겨지고, 오른쪽 아래 "✎ 공통 입력 펼치기" 로 다시 엽니다.
  - 위치와 접힘 상태는 다음에 켤 때도 그대로 기억합니다.
  공통 입력창에 쓰고 Enter -> "전송 대상" 에 체크된 칸 모두에 보내집니다.
  줄바꿈은 Shift+Enter.
  공통 입력창 위쪽 "전송 대상" 에서 보내고 싶지 않은 칸의 체크를 끄세요. (끈 칸은 흐리게 보입니다)
  쓰던 글은 자동 저장되어 앱을 다시 켜도 남아 있습니다.
  칸이 .md 파일 보기처럼 입력창이 없는 화면에 있으면, 원래 대화로 돌아가서 자동으로 보냅니다.
  각 칸 위에 결과가 표시됩니다. (✓ 보냄 / ⚠ 입력창을 찾지 못함 등)

[홈 화면 설정]
  맨 위 "⚙ 설정" 을 누르면 설정 창이 열립니다.
  칸마다 홈(⌂) 주소를 바꾸고 "저장" 을 누르세요. 앱을 켤 때도 이 화면으로 시작합니다.
  - "지금 화면 주소 넣기": 그 칸에 지금 떠 있는 화면을 홈으로 정합니다.
  - "기본값": 처음 정해 둔 프로젝트 주소로 되돌립니다.

[칸 위 버튼]
  ←  뒤로 가기      →  앞으로 가기
  ⟳  새로고침        ⌂  홈 (설정한 프로젝트 화면)
  － ＋  글씨 작게/크게 (칸이 좁아서 화면이 답답할 때 90%, 80% 로 줄여 보세요)
  사이트 안에서 오른쪽 클릭하면 복사/붙여넣기 메뉴가 나옵니다.

[Gemini 로그인]
  Gemini 칸 안의 "로그인" 버튼을 눌러 칸 안에서 바로 구글 로그인을 하세요.
  앱을 껐다 켜도 로그인이 유지됩니다.
  구글 로그인에서 "보안 키를 USB 포트에 삽입" 창은 뜨지 않게 해 두었습니다.
  (비밀번호 또는 휴대폰 확인으로 로그인하게 됩니다)

[칸 너비 조절]
  칸과 칸 사이 경계선을 마우스로 끌면 너비가 바뀝니다. (다음에 켤 때도 기억)
  경계선을 두 번 누르거나 맨 위 "배치 초기화" 를 누르면 세 칸이 같은 너비로 돌아갑니다.

[단축키]
  F11: 전체 화면 켜기/끄기    F5 또는 Ctrl+R: 마우스로 누른 칸 새로고침

[한 칸 크게 보기]
  칸 위 "⛶" 를 누르면 그 칸만 창 전체로 크게 보입니다.
  다시 원래 세 칸으로 돌아가려면 "⧉" 를 누르세요.
  칸 위 "↗" 는 지금 화면을 평소 쓰는 브라우저로 엽니다.

[구글 로그인이 막힐 때]
  "이 브라우저 또는 앱은 안전하지 않을 수 있습니다" 가 뜨면
  resources\app\src\sites.js 파일을 메모장으로 열어
    const googleLoginMode = 'chrome';
  를
    const googleLoginMode = 'firefox';
  로 바꾸고 저장한 뒤 앱을 다시 켜 보세요.

[사이트가 바뀌어서 자동 입력이 안 될 때]
  입력창/전송 버튼을 찾는 규칙은 모두
    resources\app\src\sites.js
  한 파일에 모여 있습니다. 이 파일만 고치면 됩니다.
